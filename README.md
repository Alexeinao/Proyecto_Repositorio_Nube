# Gestor de Horarios

## Descripción del proyecto

Gestor de Horarios es una aplicación web diseñada para organizar y gestionar los horarios de los trabajadores de una empresa.  
Los administradores pueden crear, editar y eliminar turnos, mientras que los empleados pueden consultar sus horarios y recibir notificaciones cuando se realicen cambios.

La aplicación utiliza Laravel como framework principal en PHP y Firebase para el almacenamiento de datos y la autenticación de usuarios.

---

## Tecnologías y herramientas

- Backend: Laravel (PHP)  
- Base de datos: Firebase Firestore
- Framework: Firebase  
- Autenticación: Firebase Authentication  
- Frontend: HTML5, CSS3
- Control de versiones: GitHub
