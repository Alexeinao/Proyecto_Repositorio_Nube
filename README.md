# Gestor de Horarios

## Descripción del proyecto

Gestor de Horarios es una aplicación web diseñada para organizar y gestionar los horarios de los trabajadores de una empresa.  
Los administradores pueden crear, editar y eliminar turnos, mientras que los empleados pueden consultar sus horarios y recibir notificaciones cuando se realicen cambios.

La aplicación utiliza Laravel como framework principal en PHP y Firebase para el almacenamiento de datos y la autenticación de usuarios.

---

## Requisitos funcionales

1. Registro e inicio de sesión mediante Firebase Authentication.  
2. Opción de cerrar sesión desde cualquier dispositivo.  
3. Gestión de trabajadores (crear, editar, eliminar, activar o desactivar).  
4. Creación, modificación y eliminación de horarios o turnos.  
5. Consulta de horarios en formato semanal o mensual.  
6. Envío de notificaciones cuando se modifique un turno.  
7. Visualización del estado de los turnos (confirmado, pendiente o modificado).  
8. Consulta de historial y estadísticas de horarios.  
9. Edición de la información personal del usuario.  
10. Cifrado de contraseñas y correos electrónicos.  
11. Detección de intentos de acceso sospechosos.  
12. Separación de roles entre administrador y trabajador.  
13. Búsqueda y filtrado de trabajadores.  
14. Eliminación de horarios antiguos o inactivos.  
15. Vista de calendario con actualizaciones en tiempo real.

---

## Requisitos no funcionales

1. Diseño visual coherente en todas las vistas.  
2. Interfaz responsive compatible con dispositivos móviles, tabletas y ordenadores.  
3. Tiempo de respuesta inferior a 3 segundos.  
4. Seguridad y confidencialidad de los datos.  
5. Integración completa con Firebase Firestore y Authentication.  
6. Actualización de datos en tiempo real.  
7. Capacidad para múltiples usuarios simultáneos.  
8. Escalabilidad para permitir futuras ampliaciones.  
9. Disponibilidad desde cualquier navegador web.  
10. Uso de buenas prácticas en Laravel y Firebase.

---

## Tecnologías y herramientas

- Backend: Laravel (PHP)  
- Base de datos: Firebase Firestore  
- Autenticación: Firebase Authentication  
- Frontend: HTML5, CSS3
- IDE: Visual Studio Code  
- Control de versiones: GitHub  
- Dependencias: Composer
